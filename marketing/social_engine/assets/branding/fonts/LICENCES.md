# Font licences

Every font here is under the SIL Open Font License 1.1, which allows use, embedding and
distribution, including in commercial work such as these reels. The full licence text sits
beside each font as `OFL.txt`. Only fonts the app itself uses are included (rule 03, spec
Section 8.4).

| Font | Used for | Source | Licence | Files |
|---|---|---|---|---|
| Cairo | Arabic text in reels | `flutter_app/assets/fonts/cairo/`, an exact copy | SIL Open Font License 1.1 | Regular, SemiBold, Bold |
| Outfit | Latin text in reels | `github.com/google/fonts`, `ofl/outfit`, fetched 2026-11-04 | SIL Open Font License 1.1 | Variable. Saved as `Outfit-Variable.ttf`, because `[` and `]` in the upstream file name do not suit URLs. The font itself is unchanged |
| Tajawal | Arabic alternate, not loaded by the templates today | `github.com/google/fonts`, `ofl/tajawal`, fetched 2026-11-04 | SIL Open Font License 1.1 | Regular, Bold |

The fonts are not modified or sold on their own, so the licence's Reserved Font Name and
no-sale conditions are not touched. Rendered video carries no obligation under the licence.
